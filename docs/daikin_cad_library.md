# DAIKIN CADライブラリ(ユーザーMac ~/Downloads/DAIKINCAD) 調査メモ 2026-08-15

- 構成: 504042/<商品群コード>/ に DXF 約14,400件(1.8GB) + 型番索引 DXF_xx.CSV(19本) + 仕様索引 504042xx.idx + KANREN2.MDB
- 索引CSV: "型番","形式","平面図","正面図","背面図","右側面図","左側面図","下面図" → 1機種=6面図DXF(複数型番が同じ図面を共有)
- 商品群: 5005300(VRV/GHP/スカイエア/ルームエアコン/ファンコイル/吹出ユニット 約9,000機種), 5005100(チラー/氷蓄熱/低温), 5005450(ベンティエール), 5005250(換気扇), 5005650/5005700(エコキュート), 5005900(除湿/空清), 5005500(加湿器)
- DXF: AC1012(R12) Shift-JIS, 実寸mm, 原点=機器中心(BASIS層に十字)
- レイヤ: OUTLINE(外形・太線) / DETAIL(詳細) / SIZE(寸法) / NOTE(注記+引出線: 冷媒液・ガス・ドレン接続口等) / SERVICESPACE(メンテスペース+ハッチ) / FIX(吊りボルト・基礎ボルト位置 円r10) / BASIS(基準線) / ARRANGE / ETC(ファイル名)
- 仕様idx: 1行目ヘッダ MAKERCODE,CGRYCODE,NAME1,NAME2,DATE,SPVER,FLA_FILE..BOT_FILE, 能力/風量/消費電力等の列(単位付き列名) → 機器表・仕様参照に使える

## MepCadでの活用案(M7 機器ライブラリ)
1. 環境設定でライブラリフォルダを指定 → CSV索引を読み込んで 商品群>形式>型番 のブラウザ
2. 配置: 平面図DXFのOUTLINE+DETAIL(+FIX/SERVICESPACEは表示切替)をブロック化、基準点=BASIS交点(原点)
3. ポート候補: NOTE層の引出線先端(接続口の位置)+文言(VP25/φ12.7等)から自動抽出、手修正可
4. 断面図用に 正面/側面図 も同じ手順で配置可能
5. 仕様idxから機器表(型番・形式・能力)出力、機器仕様書URLはBlockDefinition.linkURL
