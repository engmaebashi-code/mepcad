# MepCad(仮称)

macOS向け 空調・衛生(機械設備)用 2D CAD。

設計資料は `docs/` にあります(企画設計書・データ構造設計書・実装構成設計書・機能仕分けチェックリスト・UIモックアップ)。

## 現在の状態: Phase 1 / M4

- **選択**: クリック=1つ選択(⇧クリックで追加/除外)。**左→右ドラッグ=窓選択(完全に囲んだもの)、右→左ドラッグ=交差選択(触れたものすべて)**。⌘A=すべて選択、esc=解除、delete=削除
- **右クリックメニュー**: 選択中は最上段に **複写・移動**(以下 削除/選択解除)。未選択時は すべて選択/全体表示/グリッド切替
- **複写・移動**: 基準点→配置先の2クリック(スナップ有効・ゴーストプレビュー付き)。複写はescまで**連続配置**。数値入力も対応(`2000⏎`=カーソル方向へ2000mm、`500,-250⏎`=相対)
- **レイヤパネル**: 右端にカーソルを寄せると出るガラス調の自動格納パネル(Dock風・ピン留め可)。表示/非表示・ロック・カレント切替
- **JWWグループ展開**: JWW読込時にグループ(縮尺)ごとの下敷きレイヤを作成 — 図枠・凡例など縮尺1のグループを個別に非表示にできます。下敷きは既定ロック(選択の邪魔をしない)
- **プロパティパネル**: 選択オブジェクトの 色/線種(実線・破線・一点鎖線)/太さ/レイヤ を一括変更(すべてUndo可)
- パン: 中ボタンドラッグ or トラックパッド2本指スクロール(選択ツール中もOK)

## M3の内容

- **作図ツール**: ツールバーで 選択/線分/円/文字 を切替。線分は連続作図(esc・右クリックで終了)、角度拘束は常設パレット
- **数値入力**: 作図中に `1500⏎`=カーソル方向へ1500mm、`500,-250⏎`=相対座標、円は半径入力
- **Undo/Redo**: ⌘Z / ⇧⌘Z(ツールバーの矢印ボタンでも)
- **プレビュー**: ラバーバンドに長さ/半径をリアルタイム表示。スナップ拡張(端点/交点/中点/中心/線上+種別ラベル)

## M2の内容

- **JWW読込**: v16パーサ(JS)のSwift完全移植(`MepFormats/JwwParser.swift`)。⌘O または ツールバーのフォルダボタンでJWWファイルを開くと下敷きレイヤに取り込み、全体表示される
- **描画キャッシュ**: 図面をビットマップにキャッシュし、パン/ズーム中はキャッシュを変形表示・停止後にバックグラウンド再描画(7万線分でも軽い操作感を狙った設計)
- M1の機能: パン/ズーム/十字カーソル+ピックボックス/スナップ/ライト・ダーク切替/デモ図面

### M2の確認ポイント(フィードバック募集)

- [ ] サンプルJWW 4図面が正しく表示されるか(Jw_cadでの表示と見比べて)
- [ ] 読込時間はステータスバー右に表示 — 1秒以内か
- [ ] 7万要素の図面でパン/ズームが滑らかか(キャッシュ再生成中の一瞬のボケは仕様)
- [ ] 文字の位置・大きさの違和感(精密対応はM3)

### JWWパーサの回帰テスト

サンプルJWWファイル4点を `Tests/MepFormatsTests/Fixtures/` にコピーしてから ⌘U。
JS版パーサの解析結果(expected.json)と要素数・座標・文字が一致するか自動検証されます。

## ビルド・実行方法

1. Xcode(15以降)でこのフォルダの `Package.swift` を開く
   (Finderからフォルダごと Xcode にドロップでもOK)
2. スキームで **MepCad**、実行先に **My Mac** を選択
3. ⌘R で実行 / ⌘U でユニットテスト(MepCoreTests)

コマンドラインの場合:

```
swift run MepCad     # アプリ起動
swift test           # テスト実行
```
