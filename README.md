# MepCad(仮称)

macOS向け 空調・衛生(機械設備)用 2D CAD。

設計資料は `docs/` にあります(企画設計書・データ構造設計書・実装構成設計書・機能仕分けチェックリスト・UIモックアップ)。

## 現在の状態: Phase 1 / M4.1

### M4.1: レイヤ体系をJw_cad完全準拠に刷新

- **16グループ×16レイヤ固定構造**: JWWと同じ体系(各グループに縮尺)。変換時に情報の欠落・付け替えが起きない。用途別レイヤ(空調配管など)はグループ0のレイヤ名初期割り当てとして継続
- **JWWを開く=そのまま編集**: グループ・レイヤ構造、縮尺、表示/ロック/書込状態、**色・線種**まで引き継いで展開。下敷きロック方式は廃止(開いた図面を直接編集できます)
- **レイヤ専用パネル**: グループ4×4グリッド(Jw_cadのグループバー相当。クリック=レイヤ一覧表示、右クリック=表示/ロック)+選択グループの16レイヤ一覧。眼・錠前ボタンはクリック領域を26×24pxに拡大
- **レイヤ間の移動・複写**: 右クリックメニューとプロパティパネルから「レイヤへ移動」「レイヤへ複写」(グループ→レイヤの2段選択・Undo可)。複写後は複写先が選択されるので続けて移動などが可能

- **選択**: クリック=1つ選択(⇧クリックで追加/除外)。**左→右ドラッグ=窓選択(完全に囲んだもの)、右→左ドラッグ=交差選択(触れたものすべて)**。⌘A=すべて選択、esc=解除、delete=削除
- **右クリックメニュー**: 選択中は最上段に **複写・移動**(以下 削除/選択解除)。未選択時は すべて選択/全体表示/グリッド切替
- **複写・移動**: 基準点→配置先の2クリック(スナップ有効・ゴーストプレビュー付き)。複写はescまで**連続配置**。数値入力も対応(`2000⏎`=カーソル方向へ2000mm、`500,-250⏎`=相対)
- **自動格納パネル**: 右端にカーソルを寄せると出るガラス調パネル(Dock風・ピン留め可)。レイヤとプロパティは別カード
- **プロパティパネル**: 選択オブジェクトの 色/線種(実線・破線・一点鎖線)/太さ/レイヤ を一括変更(すべてUndo可)
- パン: 中ボタンドラッグ or トラックパッド2本指スクロール(選択ツール中もOK)

### M4.5: 作図コマンド拡充+グリッド幅選択

- **矩形**(対角2点 or `幅,高さ⏎`・単独数値=正方形。4辺は1回のUndoでまとめて戻る)
- **円弧**(中心→始点→終点方向。始点前の数値⏎=半径。反時計回り)
- **2線**(平行線: 基準線の両側に振分半々。`数値⏎`=幅変更(910等自由)、連続作図対応 — 配管のダブルライン用)
- **中心線**(一点鎖1で作図。機器・ダクトの芯押さえ)
- **点**(クリック配置。画面上は固定サイズの丸)
- **グリッド幅選択**: ステータスバーの「グリッド」がメニューに。50〜500mmの50刻みプリセット+カスタム入力(910・455・303などのモジュール寸法対応)。グリッドスナップも連動

### M4.6: 2線の振分・矩形の寸法配置・編集の角度拘束・回転

- **2線のA/B振分**: `100,50⏎`でA側(進行方向左)100・B側50を個別指定。単独数値`w⏎`は振分半々。設定は記憶
- **矩形の寸法先行指定**: 第1コーナー前に`X,Y⏎`(例: 900,600)→ 矩形がカーソル中心にぶら下がり、クリックで配置(連続配置可・escで解除)
- **移動・複写に角度拘束**: ツールバーの角度拘束パレット(90°/45°/15°)が移動・複写の方向にも効く(水平移動・垂直複写が確実に)
- **回転・回転複写**: 右クリックメニューに追加。基準点(回転中心)→方向1→方向2の2方向指定、または数値⏎で角度指定(度・反時計回り正、負で時計回り)。回転複写はescまで連続配置

### M4.7: 回転しながら配置+反転(FILDERのコマンドプロパティ相当)

- **コマンドプロパティカード**: 移動・複写中に画面左上へガラス調カードが出現。角度(0/90/180/270+自由入力)を指定すると**回転させながら決めた位置へ移動・複写**できる(ゴーストも回転して追従)
- **反転・反転複写**: 右クリックメニューに追加。**基準線を2点指示**すると選択がその線に対して鏡映される。反転複写はescまで別の基準線で連続実行可。基準線の角度拘束(90°パレット)も有効。円弧の向き・文字の角度も正しく反転(文字自体は裏返さない — CADの慣例)

### M4.8: ブロック化・ブロック解除

- **ブロック化**: 複数要素を選択し、名前と基準点を指定して1つの部品として登録。移動・複写・回転・反転でも一体として扱える
- **ブロック解除**: ブロック配置を元の基本図形へ展開。ブロック化・解除はいずれもUndo／Redo対応
- **定義と配置を分離**: 同じ部品を軽量な参照として保持し、将来の材料拾い・機器仕様書リンク・DXF/JWWブロック変換の基盤にする

### M4.8.1: ブロックの属性変更を修正

- **ブロック属性の上書き**: ブロック化後も色・線種・線幅を変更でき、配置内の全要素へ反映
- **見た目を維持して解除**: ブロック解除や入れ子ブロック化でも、配置側で変更した属性を基本図形へ引き継ぐ

### M4.9: 伸縮グリップ編集を追加

- **グリップ編集**: 選択図形に四角いハンドルを表示し、ドラッグまたはクリックで線の端点、円の半径、円弧の端点を伸縮
- **位置グリップ**: 文字・点・ブロックをグリップから移動でき、スナップにも対応
- **数値入力と角度拘束**: 線の長さや円の半径を数値指定でき、線端点の編集には角度拘束も適用

### M4.10: 用紙サイズと縮尺設定を追加

- **用紙枠**: A0〜A4の横置き用紙を選択し、実寸と書込グループの縮尺から作図範囲を表示
- **縮尺設定**: プリセットまたは自由入力で1/○を設定。図形の実寸は変えず、用紙枠が覆う範囲だけを変更
- **新規図面**: ⌘Nで用紙と縮尺を選択し、標準レイヤ構成の白紙図面を作成
- **JWW連携**: JWWヘッダの用紙コードを読み込み、用紙サイズへ反映

### M5.0: DXF読込機能を追加

- **DXF読込**: R12〜2007のモデル空間2D図形を読み込み、そのまま編集可能な図形へ変換
- **対応図形**: LINE、CIRCLE、ARC、TEXT、MTEXT、POINT、POLYLINE、LWPOLYLINE、INSERT、DIMENSIONに対応
- **ブロック・レイヤ変換**: DXFのBLOCK／INSERTをMepCadブロックへ、最大256レイヤを16グループ×16レイヤへ変換
- **文字コードと属性**: UTF-8／Shift-JIS、ACI色、線種、縮尺、用紙情報を引き継ぐ
- **実データ回帰テスト**: TOTO、LG、ダイキンのメーカーDXF 4点をテスト対象に追加

### M5.0.1: DXFのCRLF改行読込を修正

- **DXF改行対応**: Windows標準のCRLF改行と旧Mac形式のCR改行をLFへ正規化してから解析
- **メーカーDXF修正**: 実メーカーDXFで発生した読込失敗を修正し、改行形式の回帰テストを追加

### M5.1: ツールバーとファイルメニューを整理

- **ツールバー整理**: 新規・開くをファイルメニューへ、パネル固定・背景色・スナップ設定を歯車メニューへ集約
- **角度拘束表示**: 角度ボタンの表記を短縮し、ツールバー幅を節約
- **ファイルメニュー**: ⌘Nで新規図面、⌘OでJWW／DXFを開く操作をmacOS標準メニューへ統合
- **M5表示**: アプリのウィンドウタイトルをM5へ更新

### M5.2: 塗りとハッチング機能を追加

- **ハッチング作図**: 頂点を順番に指定して閉領域を作成し、Enterまたは始点クリックで確定
- **7種類のパターン**: 塗り、水平、垂直、2線、3線、クロス、レンガに対応
- **パターン設定**: A／B間隔、角度、印刷寸／実寸をプロパティカードから設定
- **DXF・JWW連携**: DXFのSOLID／HATCHとJWWソリッドを塗りエンティティとして取り込み
- **一体編集**: ハッチングを1要素として選択・移動・回転・反転・属性変更できる

### M5.3: インライン文字入力と文字パレットを追加

- **インライン文字入力**: 図面上のクリック位置へ直接入力欄を表示し、Enterで確定、escで中止
- **文字パレット**: 紙面文字高2.5／3.5／5／7mm、自由入力、文字角度を作図前に設定
- **文字の再編集**: 文字のダブルクリックまたはプロパティパネルから内容を直接編集
- **縮尺連動**: 紙面文字高を現在のグループ縮尺に合わせて実寸へ変換
- **文字プロパティ**: 選択中の文字情報と編集操作をサイドパネルへ追加

### M5.3.1: 文字の選択判定を修正

- **文字選択の修正**: 文字の基準点だけでなく、表示されている文字本体のどこをクリックしても選択可能に変更
- **回転文字対応**: 文字の幅・高さ・角度から回転後の選択範囲を計算
- **プロパティ表示**: 文字を確実に選択できるようにし、サイドパネルの文字編集項目が表示されない問題を解消
- **回帰テスト**: 通常文字と90度回転文字の選択範囲テストを追加

### M5.4: 長さ寸法記入機能を追加

- **長さ寸法**: 測定点1、測定点2、寸法線位置の3点を指定して寸法を記入
- **方向設定**: 水平・垂直・測定点に平行な寸法に対応
- **表示設定**: 端部を黒丸／矢印から選択し、補助線長さ・文字サイズ・色を設定
- **縮尺連動**: 寸法文字と補助線寸法を紙面mmから実寸へ変換
- **一体編集**: 寸法線・補助線・端部・寸法値を1要素として選択・移動・回転・反転可能
- **縦文字改善**: 90度／270度の回転文字を本体クリックで選択できるよう修正

### M5.4.1: 寸法補助線のグリップ編集を追加

- **補助線グリップ**: 寸法補助線の測定点側へグリップを追加し、ドラッグで長さを調整
- **2本同時伸縮**: どちらか一方のグリップを動かすと、両側の補助線を同じ長さへ変更
- **測定点まで復帰**: グリップを測定点近くまで伸ばすと「測定点まで」モードへ自動復帰
- **最小長保護**: 縮めすぎても補助線が消失せず、完全に非表示にする操作はプロパティ設定から実行
- **回帰テスト**: 通常伸縮、測定点までの復帰、最小長、反対側ドラッグを追加

### M5.5: 引出線文字とバルーン機能を追加

- **引出線文字**: 指示点と文字位置を指定し、傍記線付きの文字を配置可能
- **バルーン**: 文字内容に合わせた楕円枠を生成し、一重・二重枠と縦横比に対応
- **表示設定**: 矢印、文字サイズ、色、バルーンの縦横比をプロパティから変更可能
- **編集機能**: 既存の引出線・バルーンの文字編集、選択、移動などに対応
- **回帰テスト**: 引出線、バルーン、ヒット判定、作図操作のテストを追加

### M5.5.1: バルーンサイズと文字幅計算を改善

- **バルーン横サイズ**: 文字に合わせる自動設定に加え、紙面寸法による固定サイズを追加
- **サイズ統一**: 文字数が異なるバルーンでも、指定した横幅で大きさを統一可能
- **文字幅計算**: 半角文字と全角文字を別々の係数で計算し、機器番号などの枠が過大になる問題を修正
- **プロパティ編集**: 配置済みバルーンの横サイズをサイドパネルから変更可能
- **回帰テスト**: 固定幅バルーンと半角・全角文字幅のテストを追加

### M5.5.2: 複数行バルーン表示を追加

- **複数行バルーン**: 文字を「,」「，」で区切り、二段・三段のバルーンとして表示可能
- **区切り線**: 複数行の各段の間に、楕円形状に沿った水平区切り線を自動生成
- **自動サイズ調整**: 最長行の幅と行数からバルーンサイズを自動計算
- **選択判定**: 各行の文字領域を個別に計算し、複数行でも正しく選択可能
- **回帰テスト**: 複数行の分割、配置、区切り線、選択範囲のテストを追加

### M6.0: 配管作図と材料集計機能を追加

- **配管作図**: ルートを連続クリックし、Enterまたは右クリックで配管を確定する作図コマンドを追加
- **配管属性**: 用途、管種、呼び径、色、線種、口径傍記を設定可能
- **配管マスタ**: 給水・排水などの用途、VP・HIVP・SGPなどの管種、呼び径・外径をCSVで管理
- **口径傍記**: 最長区間の中央へ管種・口径を自動配置
- **材料集計**: 図面内の配管を用途・管種・呼び径別に集計し、延長と本数を表示
- **回帰テスト**: 配管形状、作図操作、配管マスタ、材料集計のテストを追加

### M6.1: 複線配管と継手・高さ設定を追加

- **複線配管**: 管の外径による2本の外形線と一点鎖線の芯線を表示可能
- **継手自動生成**: 配管の折れ点を判定し、90度・45度・その他のエルボを自動配置
- **配管高さ**: FL基準の芯高さを設定し、口径傍記へ「FL+2500」などの形式で併記可能
- **プロパティ編集**: 配置済み配管の単線・複線、継手表示、高さを一括変更可能
- **材料集計**: 用途・管種・口径別の延長と本数に加え、エルボ個数を集計
- **後方互換性**: M6.0で保存した配管データを新しい属性の既定値で読み込み可能
- **回帰テスト**: 複線形状、継手判定、高さ傍記、材料集計のテストを追加

### M6.2: 配管の高さ・立管表現と3D延長集計を追加

- **3D配管芯線**: 配管の各頂点に平面座標と高さを保持し、立体的な経路を管理可能
- **立管の自動生成**: 作図途中で高さを変更すると、同じ平面位置に立上り・立下りを自動配置
- **立管記号**: 立上りは丸印、立下りは丸と交差線で平面図へ表示
- **高さ基準面**: GL、B1FL、1FL〜5FL、RFLから図面の基準面を選択可能
- **高さ傍記**: 「50 2FL+2500」など、口径と基準面からの高さを併記
- **3D材料集計**: 水平配管だけでなく立管部分を含む実際の3D延長を集計
- **継手対応**: 水平配管と立管の接続部を90度エルボとして判定・集計
- **回帰テスト**: 立管判定、基準面、高さ傍記、3D延長、複線表示のテストを追加

### M6.3: 配管ネットワークと継手マスタを追加

- **配管ネットワーク**: 配管の接続、分岐、端部、口径変更を自動解析
- **継手自動配置**: ティーズ、レデューサ、キャップを自動生成
- **継手寸法マスタ**: 規格別・呼び径別の寸法をCSVで管理
- **材料集計**: 各種継手の個数を集計
- **回帰テスト**: 配管ネットワークと継手のテストを追加

### M6.4: 単線配管の継手シンボル表示を追加

- **単線継手表示**: 単線配管でもエルボ、ティーズ、キャップ、レデューサの位置を記号で表示
- **排水系表現**: DV系のエルボとティーズを受口ティックと丸み付きコーナーで表現

- **回帰テスト**: 排水・給水のエルボ、分岐、端部、変径シンボルのテストを追加

### M6.5: 配管継手の実形状と単線記号を改善

- **複線継手の実形状**: エルボ、ティーズ、レデューサ、キャップを規格寸法に基づく形状で描画
- **エルボ描画**: 受口と曲がり本体を分け、90度・45度の曲率と接続位置を正確に表現

- **立管記号**: 立上り・立下りの方向と接続位置が分かる記号へ改善
- **プロパティ編集**: 配置済み配管の単線記号サイズを変更可能
- **資料追加**: DV・HIVP継手カタログと単線記号仕様をdocsへ追加
- **回帰テスト**: 継手実形状、単線記号、立管、分岐、集計のテストを拡充

### M6.6: 大曲エルボと配管傍記を改善

- **大曲エルボ**: 排水配管の90度曲がりを通常エルボまたは大曲エルボから選択可能
- **規格寸法対応**: 大曲エルボの中心・受口寸法を継手マスタから取得し、単線・複線へ反映

- **継手角度維持**: 枝管の方向を変えず、移動後の主管との交点へ端部を追随
- **立体交差対応**: 高さが異なる配管は追随対象から除外
- **Undo対応**: 移動と接続配管の伸縮を1回のUndoに統合
- **ゴースト表示**: 移動中も追随後の配管形状をプレビュー

### M7.4: 配管接続追随の判定を改善

- **2段階接続判定**: 厳密な芯線接続に加え、枝端が本管の胴内にある場合も接続として判定
- **追随対象改善**: 作図時に芯線へ完全にスナップできなかった枝管も伸縮追随
- **候補選択**: 複数の接続候補から最も近い配管を選択

- **接続位置維持**: 隣接区間を伸縮させ、その先の配管は動かさない
